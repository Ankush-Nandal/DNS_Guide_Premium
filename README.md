## 📚 Curated Reference Links & Tools

Navigating the Domain Name System (DNS) efficiently requires a mix of solid theoretical documentation and reliable diagnostic utilities. Use these curated, industry-standard resources for deep-dives and live troubleshooting.

### 📑 Core Concepts & Official Documentation
*   **Cloudflare Learning:** [Cloudflare DNS Overview](https://www.cloudflare.com/learning/dns/what-is-dns/) — A deep dive into the foundational differences between recursive resolvers and authoritative nameservers.
*   **IBM Technology Resources:** [IBM: What Are DNS Records?](https://www.ibm.com/topics/dns-data-records) — A clear, structured breakdown of essential resource records like NS, MX, and TXT.
*   **IETF & IANA Standards:** [IANA DNS Parameters](https://www.iana.org/assignments/dns-parameters/dns-parameters.xhtml) — The definitive, official registry for DNS classes, opcodes, and standard resource record types.

### 🔍 Live Lookup & Diagnostic Utilities
*   **MxToolbox:** [MxToolbox MX Lookup](https://mxtoolbox.com/) — Quickly diagnose mail server routing, SPF/DKIM validation, and general domain health.
*   **Nslookup.io:** [Nslookup.io Web Tool](https://www.nslookup.io/) — An excellent web-based tool to instantly check specific records and inspect active IPv4/IPv6 domain configurations.
*   **DNS Checker:** [DNSChecker Propagation Tool](https://dnschecker.org/) — Globally verify DNS propagation across dozens of international nameservers simultaneously.

### 🌐 Secure Public DNS Endpoints
*   **Google Public DNS:** [Google DNS for Developers](https://developers.google.com/speed/public-dns) — Infrastructure details, performance features, and standard Anycast IP endpoints (`8.8.8.8` / `8.8.4.4`).
*   **Cloudflare 1.1.1.1:** [Cloudflare Encryption Features](https://1.1.1.1/) — Implementation workflows for secure modern protocols like DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT).
